    MDR-CAT  -- cccc

Catalogue of a ZX Microdrive cartridge image (.MDR file)
whose name follows on the same input line. The label,
every label with its count when they differ, and "write
protected" when it is. One line per file, sorted by name:
type (Prog, Numb, Char, Code, Scrn, Prnt), length, name,
and for non-PRINT files the start address, the bytes
actually used and, for a program, the vars offset and the
autostart line. A file whose record 0 is lost is "Bad!",
with its sectors. Then the bad sectors, one a line, and
the totals of used, bad and free space.

Read-only: the cartridge is never written.
Example: MDR-CAT M2.MDR

See MDR-SECTORS, MDR-INFO, MDR-GET. Available after NEEDS MDR
