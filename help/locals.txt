    LOCALS   --

Compile-only. { ... } declares named locals in place, first
in the definition:  : SUM3 { X Y Z } X Y + Z + ; . Read a
local by name, write it with TO. Maximum 8, input and
output combined.

An optional -- inside { } marks output locals: not read from
the stack, created at 0 on every entry, and pushed
automatically (in declaration order) by every exit path,
e.g.  : SUM-TO { N -- ACC } ... ; . See HELP { and HELP --.

Binding is by save-and-restore: each cell's previous content
goes on the return stack and is restored on every exit path,
so the word is re-entrant and may RECURSE. Each activation
costs 4+4n bytes of the 160-byte return stack: keep
recursion shallow.

See also: the older two-part form, LOCALS-FOR + LOCALS.
